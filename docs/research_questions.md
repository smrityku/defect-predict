# Research Questions

**DefectInsight: An Explainable Industrial Software Defect Prediction Framework**

## RQ1

Can one pipeline generalize across heterogeneous repositories?

## RQ2

Which classifiers perform consistently across repeated stratified validation?

## RQ3

Which software metrics contribute most to file-level defect prediction?

## RQ4

Can explainability outputs improve developer prioritization of risky files?
